# Construction-Expense-Tracker
A Machine Learning-based web application developed to simplify construction cost estimation and project expense tracking. The system predicts construction expenses based on building dimensions and project-related inputs, helping users manage budgets more efficiently.


Features

-Construction cost forecasting using Machine Learning models

-Interactive and responsive frontend built with React.js

-Python backend for data processing and prediction

-Budget estimation based on construction parameters

-User-friendly interface for efficient project management
